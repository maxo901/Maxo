# پیام‌رسان (شبیه تلگرام) — نسخه ۲

Node.js + Express + Socket.IO + SQLite — بدون Build، یک سرویس واحد.

## دیپلوی روی Railway

1. پروژه را روی GitHub بگذار → Railway: **New Project → Deploy from GitHub**.
2. **Volume** بساز و Mount Path را `/data` بگذار (بدون Volume با هر دیپلوی همه چیز پاک می‌شود).
3. در **Variables** اضافه کن:

| متغیر | مقدار |
|---|---|
| `PORT` | `8080` |
| `DATA_DIR` | `/data` |
| `OWNER_USERNAME` | آیدی خودت (این کاربر مالک می‌شود). اگر خالی بماند، **اولین ثبت‌نام‌کننده** مالک است؛ پس بعد از دیپلوی اول از همه ثبت‌نام کن. |
| `APP_NAME` | نام برنامه (اختیاری) |

ایمیل و کد تأیید دیگر لازم نیست (`MAIL_FROM`، `RESEND_API_KEY` و … را می‌توانی پاک کنی). دیتابیس قدیمی خودکار ارتقا پیدا می‌کند.

## چه چیزهایی جدید است

- ثبت‌نام بدون کد تأیید (ایمیل اختیاری)؛ تغییر رمز؛ روشن/خاموش کردن «آنلاین بودن»
- زبان: اولین بار می‌پرسد — فارسی، English، 中文، العربية، Português (Brasil)، Türkçe، Русский، Español، Français
- تنظیمات بدون دیالوگ (همه‌چیز صفحه‌ی کشویی است): ۹ تم، پس‌زمینه‌ی چت (گرادیانت یا عکس خودت + طرح)، اندازه متن، گردی پیام‌ها، انیمیشن
- ویرایشگر عکس قبل از ارسال: برش، چرخش، نور، کنتراست، اشباع، گرمی، نقاشی با قلم، متن، کپشن
- گروه و کانال: هر کاربر می‌سازد، لینک دعوت (`/g/…` برای گروه، `/c/…` برای کانال)، تغییر عکس/نام توسط ادمین
- گروه‌هایی که **مالک** می‌سازد «رسمی» است: همه (حتی کاربران جدید) خودکار عضو می‌شوند و نمی‌توانند ترک کنند
- استوری عکس/ویدیو (۲۴ ساعت، با لیست بازدیدکننده)، پیام‌های ذخیره‌شده برای همه
- حذف دوطرفه‌ی پیام، «حذف فقط برای من»، پاک‌کردن تاریخچه (برای من / برای هر دو)، فوروارد، ایموجی‌پیکر
- پروفایل کاربر: اطلاعات، گروه‌های مشترک، رسانه‌های مشترک؛ مالک ایمیل کاربران را هم می‌بیند

## توسعه محلی

```
npm install
npm start      # http://localhost:8080
```
