# پیام‌رسان (شبیه تلگرام)

Node.js + Express + Socket.IO + SQLite — بدون Build، یک سرویس واحد.

## دیپلوی روی Railway

1. پروژه را روی GitHub بگذار → Railway: **New Project → Deploy from GitHub**.
2. **Volume** بساز و Mount Path را `/data` بگذار (بدون Volume با هر دیپلوی همه چیز پاک می‌شود).
3. در **Variables** اضافه کن:

| متغیر | مقدار |
|---|---|
| `PORT` | `8080` |
| `DATA_DIR` | `/data` |
| `OWNER_EMAIL` | ایمیل خودت (این ایمیل مالک می‌شود؛ اگر خالی باشد، اولین ثبت‌نام‌کننده مالک است) |
| `APP_NAME` | نام برنامه (اختیاری) |
| `MAIL_FROM` | مثلاً `پیام‌رسان <noreply@yourdomain.com>` |
| `RESEND_API_KEY` **یا** `BREVO_API_KEY` **یا** `SMTP_*` | برای ارسال کد تأیید |

4. **Settings → Networking → Custom Domain** → دامنه‌ات را اضافه کن، Target Port = `8080`.

## ایمیل

- Railway روی پلن‌های Free/Hobby پورت SMTP را می‌بندد؛ از **Resend** یا **Brevo** (API روی HTTPS) استفاده کن.
- Resend فقط بعد از تأیید دامنه به همه ایمیل‌ها می‌فرستد. Brevo با یک Sender تأییدشده کار می‌کند (`MAIL_FROM` باید ایمیل ساده باشد).
- اگر هیچ کدام تنظیم نشود، کد تأیید فقط در **Logs** سرور چاپ می‌شود (برای تست).

## قابلیت‌ها

ثبت‌نام با کد ایمیل · ورود با ایمیل/آیدی · آیدی یکتا (بررسی لحظه‌ای) · پروفایل و بیو و عکس · گروه (فقط مالک می‌سازد/می‌بندد/حذف می‌کند) · پیوی بین کاربران · عکس، ویدیو، ویس (ضبط داخل برنامه) و فایل · پاسخ (Reply) · ری‌اکشن · ویرایش و حذف پیام · تیک خوانده‌شدن · تاریخ شمسی · کاربران آنلاین و «در حال نوشتن» · مسدود کردن کاربر (مالک) · حذف حساب · حالت شب/روز · موبایل‌فرندلی.
